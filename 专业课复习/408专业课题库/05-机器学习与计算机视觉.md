# 机器学习与计算机视觉

> 这一部分结合 YOLOv8 + CBAM 钢材缺陷检测项目复习。先背“简答”，再看“补充”。

## 一、必考级基础

### 1. 什么是过拟合？如何解决？

**简答：**过拟合是指模型在训练集上表现很好，但在测试集或新数据上表现较差。常用方法有：增加数据或做数据增强、加入正则化、使用 Dropout、降低模型复杂度、提前停止训练。

**补充：**过拟合说明模型记住了训练样本中的细节和噪声，却没有学到能推广到新数据的规律。解决时应结合验证集观察训练误差和验证误差的变化，不能只看训练集准确率。

### 2. 准确率、精确率、召回率、F1 值有什么区别？

**简答：**准确率是预测正确的样本占全部样本的比例。精确率表示预测为正的样本中有多少是真的正样本。召回率表示所有正样本中有多少被找出来。F1 值是精确率和召回率的调和平均。缺陷检测通常更关注召回率，因为漏掉缺陷可能造成更大损失。

**公式：**

- Accuracy = `(TP + TN) / (TP + TN + FP + FN)`
- Precision = `TP / (TP + FP)`
- Recall = `TP / (TP + FN)`
- F1 = `2 × Precision × Recall / (Precision + Recall)`

**补充：**当正常样本远多于缺陷样本时，单看准确率可能会产生误导。例如模型把所有图片都判断为正常，准确率仍可能很高，但召回率为 0。

### 3. 为什么卷积神经网络适合处理图像？

**简答：**卷积神经网络有局部感受野和参数共享，可以提取图像中的空间特征，同时大幅减少参数量。浅层可以学习边缘和纹理，深层可以学习目标的形状和语义。

**补充：**卷积核在图像的不同位置重复使用，因此同一个卷积核可以检测不同位置的相同模式。池化或步长卷积还能逐步扩大感受野，降低特征图大小。

### 4. YOLO 的基本原理是什么？

**简答：**YOLO 是单阶段目标检测方法。它只需要一次前向传播，就能同时预测目标的类别、位置和置信度，然后通过 NMS 去掉重复框。

**补充：**输入图像经过骨干网络提取特征，再由 Neck 融合不同尺度的特征，检测头输出边界框和类别结果。YOLO 速度快，适合实时检测，但对很小的目标或密集目标可能更难检测。

### 5. IoU、NMS、mAP@0.5 分别是什么？

**简答：**IoU 是预测框和真实框的交并比，用来衡量位置重合程度。NMS 是非极大值抑制，用来删除同一目标的重复预测框。mAP@0.5 是在 IoU 阈值为 0.5 时，各类别 AP 的平均值。

**补充：**NMS 会先保留置信度最高的框，再删除与它 IoU 过高的其他框，重复这个过程直到处理完所有框。AP 是某个类别的精确率—召回率曲线下面积，mAP 是所有类别 AP 的平均值。

## 二、结合项目高概率考

### 6. 为什么裂纹是最难检测的类别？

**简答：**裂纹通常纹理较弱、形状细长、边界模糊，并且与背景的差异较小，所以模型不容易找到稳定特征，容易漏检。

**补充：**裂纹的长度、方向和宽度变化很大，部分裂纹还会受到光照、噪声和模糊影响。因此可以重点检查小裂纹、低对比度裂纹的错误案例，并尝试更高分辨率输入、难例挖掘和针对弱纹理的数据增强。

### 7. CBAM 是什么？为什么能提升检测效果？

**简答：**CBAM 是一种轻量级注意力模块，包含通道注意力和空间注意力。通道注意力回答“关注什么特征”，空间注意力回答“关注什么位置”。它能让模型加强缺陷相关特征，减少无关背景的影响。

**补充：**CBAM 通常先在通道维度计算权重，再在空间维度计算权重。它不需要大幅增加网络参数，因此适合加入已有检测器。在裂纹检测中，它可能帮助模型关注细小的纹理和边缘变化。

### 8. 为什么把 CBAM 放在 YOLOv8 的 Neck 部分？

**简答：**Neck 负责融合不同尺度的特征。在特征融合阶段加入 CBAM，可以突出与缺陷有关的通道和空间位置，再交给检测头预测。这样既利用了多尺度信息，又不会在 Backbone 的每个模块都增加计算量。

**补充：**裂纹可能很小，也可能跨越较大区域，多尺度特征对它很重要。把 CBAM 放在 Neck 是一种设计选择，结论应由对比实验支持，不能直接说它一定是最优位置。

### 9. 如何证明 CBAM 的改进是有效的？

**简答：**要做控制变量实验和消融实验。基线模型和加入 CBAM 的模型使用相同数据划分、预处理、增强方式、输入设置、优化器和训练超参数，只改变是否加入 CBAM，然后比较 mAP、分类别 AP、Precision、Recall 和速度。最好使用多个随机种子重复实验。

**补充：**除了报告平均结果，还应报告标准差，并检查提升是否稳定。还可以进一步比较 CBAM 放在不同位置、只使用通道注意力或只使用空间注意力的结果，这样才能说明具体是哪一部分带来了提升。

### 10. 除了 mAP 提升，还要关注哪些指标？

**简答：**还要关注 Precision、Recall、分类别 AP、漏检率、误检率和推理速度。工业缺陷检测通常优先减少漏检，但也要考虑误检过多会增加人工复查成本。

**补充：**如果模型部署到真实产线，还应测试不同光照、速度、设备和缺陷大小下的表现，并评估完整处理链路的延迟，而不是只看单张图片的推理时间。最终阈值应根据漏检和误检的实际代价来设置。
