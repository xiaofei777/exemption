# 实习经历

## 武汉金银湖实验室

**Question: Tell us about your research internship.**  
请介绍你的科研实习经历。

> At Wuhan Jinyinhu Laboratory, I worked on a software supply-chain security platform and an LLM application. I built over fifteen ECharts charts, such as a threat map, a CVE trend chart, and a high-risk list. I also made a three-step GeoJSON backup plan and API backup handling for weak network conditions. In TcodeAI, I helped write clear repair advice for software problems and reused the same chart design on more than three pages. I learned to care about system stability, easy maintenance, and user needs when adding AI to a real product.

在武汉金银湖实验室，我参与了软件供应链安全平台和大语言模型应用的开发。我制作了 15 个以上的 ECharts 图表，例如威胁地图、CVE 趋势图和高风险列表。我还针对网络不稳定设计了三级 GeoJSON 备用方案和接口备用处理。在 TcodeAI 中，我帮助编写清晰的软件问题修复建议，并将相同的图表设计复用到三个以上的页面。这段经历让我认识到，把 AI 加入真实产品时，要关注系统稳定性、维护方便和用户需求。
