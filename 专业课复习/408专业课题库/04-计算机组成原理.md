# 计算机组成原理

**Q：Cache 为什么有效？**  
答：程序有时间局部性和空间局部性。Cache 保存最近使用和附近的数据，可以减少访问主存的平均时间。

**Q：Cache 的映射方式有哪些？**  
答：直接映射、全相联映射、组相联映射。

**Q：一条指令的基本执行过程？**  
答：取指、译码、执行、访存、写回。

**Q：什么是指令流水线？**  
答：把指令执行分成多个阶段，让多条指令重叠执行，提高吞吐率。常见冲突有结构冲突、数据冲突和控制冲突。

**Q：中断和异常的区别？**  
答：中断通常来自外部硬件；异常通常由当前指令执行引起。

**Q：中断和 DMA 的区别？**  
答：中断需要 CPU 参与传输；DMA 可直接在内存和外设之间传输，减少 CPU 负担。

**Q：SRAM 和 DRAM 的区别？**  
答：SRAM 速度快、成本高、不需要刷新；DRAM 集成度高、成本低，但需要定期刷新。

**Q：为什么 GPU 适合深度学习？**  
答：深度学习有大量可并行的矩阵和向量运算，GPU 有很多并行计算单元和较高的内存带宽。

## 稍详细理解

Cache 命中时直接从高速缓存取数据，未命中时才访问主存并把数据装入 Cache。流水线能提高单位时间完成的指令数，但不能明显缩短单条指令的全部时间；遇到数据相关时可能需要暂停或转发。DMA 适合大块数据传输，CPU 只需设置参数并在传输完成后处理中断。GPU 的优势来自大量相同类型的并行运算，但遇到分支多、任务不规则的程序时优势会减弱。
