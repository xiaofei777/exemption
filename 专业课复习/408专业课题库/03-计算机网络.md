# 计算机网络

**Q：TCP 和 UDP 的区别？**  
答：TCP 面向连接、可靠、有序，有流量控制和拥塞控制；UDP 无连接、开销小、延迟低，但不保证可靠。

**Q：TCP 三次握手为什么是三次？**  
答：确认双方的发送和接收能力，并同步初始序列号，避免旧请求造成错误连接。

**Q：TCP 四次挥手为什么是四次？**  
答：TCP 是全双工通信，两个方向要分别关闭；FIN 和 ACK 通常不能合并。

**Q：TIME_WAIT 的作用？**  
答：确保最后一个 ACK 能到达，并让旧连接的延迟报文消失。

**Q：TCP 如何保证可靠传输？**  
答：序列号、确认应答、超时重传、校验和、滑动窗口。

**Q：流量控制和拥塞控制的区别？**  
答：流量控制针对接收方的处理能力；拥塞控制针对整个网络的情况。

**Q：HTTP 和 HTTPS 的区别？**  
答：HTTPS = HTTP + TLS，提供加密、身份认证和数据完整性保护。

**Q：DNS 解析大致过程？**  
答：浏览器缓存 → 操作系统缓存 → 本地域名服务器 → 根域名服务器 → 顶级域名服务器 → 权威域名服务器。

**Q：常见 HTTP 状态码？**  
答：`200` 成功；`301/302` 重定向；`400` 请求错误；`401` 未认证；`403` 无权限；`404` 资源不存在；`500` 服务器错误。

## 稍详细理解

TCP 建立连接时，客户端和服务器分别发送 SYN、SYN+ACK、ACK，双方都确认了序列号后才能通信。拥塞控制通常经历慢启动、拥塞避免、快速重传和快速恢复。HTTPS 不只是加密，还通过证书确认服务器身份，防止中间人篡改。实际排查网络问题时，可以按 DNS、TCP 连接、TLS 握手、HTTP 请求的顺序定位。
