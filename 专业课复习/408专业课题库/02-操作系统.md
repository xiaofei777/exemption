# 操作系统

**Q：进程和线程的区别？**  
答：进程是资源分配的基本单位，线程是 CPU 调度的基本单位。同一进程的线程共享地址空间，但有独立的栈和寄存器。

**Q：死锁的四个必要条件？**  
答：互斥、占有并等待、不可剥夺、循环等待。

**Q：死锁如何解决？**  
答：预防、避免、检测与解除；银行家算法属于死锁避免。

**Q：分页和分段有什么区别？**  
答：分页大小固定，主要用于内存管理；分段按程序逻辑划分，大小可变。

**Q：什么是虚拟内存？**  
答：利用磁盘和部分内存，为进程提供比实际物理内存更大的地址空间，通常通过分页实现。

**Q：FIFO、LRU、OPT 页面置换有何区别？**  
答：FIFO 淘汰最早进入的页面，可能出现 Belady 异常；LRU 淘汰最长时间没用的页面；OPT 淘汰未来最长时间不会用的页面，理论上最好。

**Q：select、poll、epoll 的区别？**  
答：select 和 poll 需要遍历文件描述符；epoll 用事件通知，遍历更少，适合大量连接。

**Q：什么是临界区？**  
答：访问共享资源的代码区域，需要互斥机制保证同一时刻只有一个线程进入。

## 稍详细理解

进程之间地址空间隔离，出错时通常不会影响其他进程；线程共享进程资源，因此切换开销小，但需要注意同步。解决死锁时，预防是破坏必要条件，避免是分配前判断是否安全，检测与解除则允许死锁发生后再处理。虚拟内存通过页表把虚拟地址映射到物理地址，缺页时由操作系统把页面换入内存。
