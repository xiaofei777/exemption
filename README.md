# 推免材料仓库

计算机专业推免（保研）全套申请材料，涵盖简历、套磁、面试准备与专业课复习。

## 目录结构

```
.
├── 推免简历.html              # 主简历（宋体排版，浏览器打开 → 打印为 PDF）
├── 个人资料整理.html          # 简历 + 个人自述 + 成绩单/证书扫描件（多页文档）
├── 个人自述.md                # 个人自述精简版
├── 保研推免自我介绍.md        # 面试用自我介绍逐字稿
├── 预推免报名速填卡.md        # 各校预推免系统报名信息速查
├── 面试问题准备-项目一.html   # 项目一高频面试问题与回答要点
│
├── 推免套磁/                  # 套磁材料（按学校分目录）
│   ├── 脚本/                  #   各校批量生成个性化套磁信的 Python 脚本
│   ├── 套磁信模板.md          #   通用套磁信模板
│   ├── 保研套磁统计表.xlsx    #   投递进度跟踪表
│   └── <学校名>/              #   教师名录调研、个性化套磁信、已投递归档
│
├── 专业课复习/                # 408 专业课面试速成题库（md + docx）
├── 项目一/                    # 项目一内容与知识点详解
├── 英语准备/                  # 英语面试背诵稿及 PDF
├── assets/                    # 证件照、证书扫描件等图片资源
└── 面试PPT/                   # 面试 PPT（已 gitignore，仅本地保留）
```

## 套磁信脚本使用

各校套磁信由脚本从「教师名录 HTML」+「通用模板」批量生成：

```bash
python3 推免套磁/脚本/generate_whut_letters.py   # 武汉理工大学
python3 推免套磁/脚本/generate_nwpu_letters.py   # 西北工业大学
# ...其余同理，脚本内含绝对路径，任意目录运行均可
```

脚本命名规则：`generate_<学校缩写>_letters.py`（如 whut/北交大 bjtu/华师 ccnu 等）。

## 说明

- 简历类 HTML 均为 A4 打印优化，浏览器打开后 Ctrl/Cmd+P 导出 PDF
- `面试PPT/` 含敏感个人信息，已在 `.gitignore` 中排除，不会推送到远程
- 仓库含个人隐私信息（手机号、成绩单等），请勿公开分享
