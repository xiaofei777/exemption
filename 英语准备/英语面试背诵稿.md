## 0. 面试时的基本原则

- 语速放慢，每句话只表达一个意思。
- 数字只说简历中能解释清楚的：`16 out of 207`、`top 7.7%`、`80%`、`0.5 seconds`、`3 milliseconds`。
- 项目回答按 **problem → method → result → my contribution** 展开。
- 没听清就请求重复；需要思考就停两秒，不要连续说 `umm`。

## 3. 核心项目一：CamTalk

### 3.1 Please introduce one AI-related project you have done.（请介绍一个你做过的人工智能项目。）

> One representative project is CamTalk, a real-time multimodal vision dialogue agent. The target scenario required both data minimization and low latency. My main contribution was a lightweight key-frame sampling method based on voice activity detection and pixel differences. When the user was silent or the visual content barely changed, the system avoided sending redundant frames. This reduced the upload volume during silent periods by about 80 percent.

**中文翻译：**一个有代表性的项目是 CamTalk，一个实时多模态视觉对话智能体。目标场景同时要求减少数据量并保持低延迟。我的主要贡献是设计了一种基于语音活动检测和像素差异的轻量级关键帧采样方法。当用户处于静默状态或画面内容变化很小时，系统会避免发送重复帧，使静默期间的数据上传量降低约 80%。
>
> I also participated in the streaming orchestration of seven nodes: speech-to-text, the large language model, and text-to-speech, together with the supporting processing nodes. We used incremental text and audio delivery, so the user could receive partial results before the whole response was finished. The end-to-end perception latency was kept below 0.5 seconds. This project improved my understanding of multimodal interaction, system latency, and the gap between a model demo and a reliable product.

**中文翻译：**我还参与了七个节点的流式编排，包括语音转文字、大语言模型、文字转语音以及配套处理节点。我们采用文本和音频增量传输，使用户在完整回答生成之前就能收到部分结果。端到端感知延迟控制在 0.5 秒以内。这个项目加深了我对多模态交互、系统延迟，以及模型演示与可靠产品之间差距的理解。

### 3.2 What was your specific contribution?（你的具体贡献是什么？）

> I was the project leader. My most specific contribution was the key-frame sampling algorithm. I compared the current frame with a reference frame using pixel-level differences and used a threshold to decide whether a new frame should be uploaded. I also worked on the STT–LLM–TTS streaming workflow and the integration of the modules. My focus was to reduce unnecessary data transfer while keeping the visual information useful for the dialogue model.

**中文翻译：**我是这个项目的负责人。我的具体贡献主要是关键帧采样算法：通过像素级差异比较当前帧和参考帧，再使用阈值判断是否需要上传新帧。我还参与了 STT–LLM–TTS 流式工作流和各模块的集成。我的重点是在保留对话模型所需视觉信息的同时，减少不必要的数据传输。

### 3.3 Why did you choose pixel differences instead of uploading every frame?（为什么选择像素差异，而不是上传每一帧？）

> Uploading every frame is wasteful because many consecutive frames contain almost the same information. Pixel differences are simple, fast, and can run close to the data source. They reduce bandwidth and processing cost without requiring an additional heavy model. The trade-off is that a fixed threshold may miss subtle changes, so an adaptive threshold or a learned sampler would be a valuable next step.

**中文翻译：**上传每一帧会造成浪费，因为许多连续帧包含的几乎是相同信息。像素差异方法简单、快速，可以在靠近数据源的位置运行；它不需要额外的重型模型，就能降低带宽和处理成本。它的不足是固定阈值可能漏掉细微变化，因此自适应阈值或学习式采样器是有价值的下一步方向。

### 3.4 How did you reduce latency?（你是如何降低延迟的？）

> We used a streaming design instead of waiting for the complete pipeline to finish. Speech, text, and audio were processed incrementally, and the output of one node was passed to the next node as soon as partial data became available. This reduced the user's waiting time. In practice, the end-to-end perception latency was below 0.5 seconds.

**中文翻译：**我们采用流式设计，而不是等待完整链路全部结束。语音、文本和音频都以增量方式处理，一个节点一旦产生部分数据，就立即传给下一个节点。这样减少了用户的等待时间。在实际测试中，端到端感知延迟低于 0.5 秒。

### 3.5 What are the limitations of this project?（这个项目有哪些局限？）

> First, pixel-difference sampling can be sensitive to camera motion, illumination changes, and the choice of threshold. Second, the current system mainly focuses on interaction latency and data reduction, so a more systematic evaluation of answer quality and robustness is still needed. I would next test it under different scenes and devices, use adaptive sampling, and evaluate both latency and task-level accuracy.

**中文翻译：**第一，像素差异采样可能受到摄像头运动、光照变化和阈值选择的影响。第二，目前系统主要关注交互延迟和数据压缩，因此还需要更系统地评估回答质量和鲁棒性。下一步我会在不同场景和设备上测试，采用自适应采样，并同时评估延迟和任务层面的准确性。

## 4. 核心项目二：YOLOv8 + CBAM 缺陷检测

### 4.1 Please explain your steel-defect detection project.（请介绍你的钢材缺陷检测项目。）

> The project focused on online surface-defect inspection for hot-rolled steel. We used the public NEU-DET dataset, which contains 1,800 images and six typical defect categories. The main problem was missed detection of cracks. In the baseline YOLOv8 model, the crack class had an AP at IoU 0.5 of only 52.2 percent. By visualizing missed samples, I found weak texture and unclear boundaries to be important factors.

**中文翻译：**这个项目面向热轧带钢的在线表面缺陷检测。我们使用了公开的 NEU-DET 数据集，其中包含 1,800 张图像和 6 类典型缺陷。主要问题是裂纹漏检。在基线 YOLOv8 模型中，裂纹类别在 IoU 为 0.5 时的 AP 只有 52.2%。通过可视化漏检样本，我发现弱纹理和边界不清晰是重要原因。
>
> To improve the feature representation, I inserted CBAM, or the Convolutional Block Attention Module, into the Neck of YOLOv8. CBAM applies channel attention and then spatial attention. The channel part emphasizes useful feature channels, while the spatial part emphasizes useful locations in a feature map. In a controlled ablation experiment with the same data and hyperparameters, the overall mAP at IoU 0.5 increased from 77.5 percent to about 80 to 81 percent. The crack AP increased to about 57 to 60 percent, and the inference time was about 3 milliseconds per image.

**中文翻译：**为了改进特征表达，我将 CBAM，也就是卷积块注意力模块，加入 YOLOv8 的 Neck。CBAM 先使用通道注意力，再使用空间注意力。通道部分强调有用的特征通道，空间部分强调特征图中有用的位置。在数据和超参数相同的控制变量消融实验中，IoU 为 0.5 时的整体 mAP 从 77.5% 提升到约 80%～81%。裂纹 AP 提升到约 57%～60%，单张图像推理时间约为 3 毫秒。

### 4.2 What is CBAM, and why does it help?（什么是 CBAM？它为什么有效？）

> CBAM is a lightweight attention module with two sequential steps. Channel attention asks which feature channels are important. It uses both average pooling and maximum pooling to summarize global information, because average pooling describes the general response while maximum pooling preserves strong local evidence. Spatial attention then asks which positions are important by aggregating information across channels. For weak-texture cracks, this can help the detector focus on subtle but informative patterns.

**中文翻译：**CBAM 是一个轻量级注意力模块，包含两个依次进行的步骤。通道注意力判断哪些特征通道更重要。它同时使用平均池化和最大池化来概括全局信息，因为平均池化描述整体响应，最大池化则保留较强的局部证据。接着，空间注意力通过聚合不同通道的信息，判断哪些位置更重要。对于弱纹理裂纹，这可以帮助检测器关注细微但有用的模式。

### 4.3 Why did you put CBAM in the Neck?（为什么把 CBAM 放在 Neck？）

> The Neck fuses features from different scales, so it is a reasonable place to refine the already integrated representation before the detection head makes predictions. It also keeps the modification relatively lightweight compared with adding attention to every backbone block. In this project, the Neck placement was a design choice based on multi-scale feature fusion and computation constraints. I did not claim a complete comparison of every possible insertion position; that comparison would be part of a more rigorous follow-up study.

**中文翻译：**Neck 会融合不同尺度的特征，因此在检测头进行预测之前，用它来优化已经融合的特征表示是合理的。与在 Backbone 的每个模块中都加入注意力相比，这种改动也相对轻量。在本项目中，把 CBAM 放在 Neck 是基于多尺度特征融合和计算开销约束做出的设计选择。我没有声称已经完成了所有插入位置的全面比较；这种比较属于后续更严谨的研究内容。

### 4.4 How did you make the experiment credible?（你如何保证实验可信？）

> I used a controlled ablation setup. The baseline and the CBAM version used the same dataset split, preprocessing, data augmentation, input setting, optimizer, learning-rate schedule, and training hyperparameters. The only intended change was whether CBAM was added. The result supports the conclusion that CBAM was helpful under this setup. A stronger study should also repeat the experiment with multiple random seeds and report the mean and standard deviation.

**中文翻译：**我采用了控制变量的消融实验。基线版本和 CBAM 版本使用相同的数据划分、预处理、数据增强、输入设置、优化器、学习率策略和训练超参数。唯一计划改变的因素是是否加入 CBAM。结果支持这样的结论：在当前实验设置下，CBAM 起到了积极作用。更严谨的研究还应使用多个随机种子重复实验，并报告均值和标准差。

### 4.5 What is the difference between AP and mAP?（AP 和 mAP 有什么区别？）

> AP is the area under the precision-recall curve for one class. mAP is the mean AP across all classes. Therefore, 52.2 percent is the AP of the crack class, while 77.5 percent and about 80 to 81 percent are overall mAP values. The notation “at IoU 0.5” means that a predicted box is considered correctly localized when its intersection-over-union with the ground-truth box reaches the 0.5 threshold.

**中文翻译：**AP 是某一个类别的精确率—召回率曲线下面积，mAP 则是所有类别 AP 的平均值。因此，52.2% 是裂纹类别的 AP，而 77.5% 和约 80%～81% 是整体 mAP。“IoU 为 0.5”表示：当预测框与真实框的交并比达到 0.5 阈值时，才认为定位正确。

### 4.6 What would you do next to improve recall?（下一步你会如何提高召回率？）

> I would first collect and review false-negative samples, especially small, blurred, and low-contrast cracks. Then I would consider hard-example mining, class-balanced sampling, and augmentation designed for weak textures. I would also compare attention modules such as SE or ECA, and evaluate the precision-recall trade-off because industrial inspection usually gives a high cost to missed defects. Every change should be tested with the same evaluation protocol.

**中文翻译：**我会先收集并复查假阴性样本，尤其是尺寸小、模糊和低对比度的裂纹。然后考虑难例挖掘、类别均衡采样，以及针对弱纹理设计的数据增强。我还会比较 SE、ECA 等注意力模块，并评估精确率和召回率之间的权衡，因为工业质检通常非常重视漏检缺陷的代价。每项改动都应使用相同的评估协议进行测试。

### 4.7 Can the result transfer to a real production line?（这个结果能迁移到真实产线吗？）

> NEU-DET is a public benchmark with relatively controlled imaging conditions. A real production line may include illumination changes, motion blur, vibration, small defects, and class imbalance. I would first collect a representative in-domain validation set, measure the domain gap, and then calibrate the model and threshold for the production cost. Deployment would also require profiling the complete pipeline, not only the model's single-image inference time.

**中文翻译：**NEU-DET 是一个公开基准数据集，成像条件相对可控。真实产线可能存在光照变化、运动模糊、设备振动、小尺寸缺陷和类别不均衡等问题。我会先收集具有代表性的同域验证集，衡量领域差异，再根据产线的实际代价校准模型和判断阈值。部署时还需要评估完整处理链路的性能，而不能只看模型的单张图像推理时间。

## 7. 文献朗读与翻译：可背的过渡句

### 7.1 朗读前快速组织

> Let me first identify the main subject and the main verb.

**中文翻译：**我先找出句子的主语和主要谓语。
>
> This sentence mainly describes the problem, the proposed method, and the result.

**中文翻译：**这句话主要描述了问题、提出的方法和取得的结果。

### 7.2 翻译卡顿时

> This part means that the method is designed to...

**中文翻译：**这部分的意思是，该方法旨在……
>
> In simpler words, the authors want to...

**中文翻译：**简单来说，作者希望……
>
> The exact term is not familiar to me, but from the context it refers to...

**中文翻译：**我对这个术语的准确含义还不熟悉，但结合上下文，它应该指的是……

### 7.3 AI 摘要常用句式

- `To address this problem, we propose...`：为解决这一问题，本文提出……
- `The proposed method consists of three main components.`：所提出的方法由三个主要部分组成。
- `Compared with the baseline, our method improves...`：与基线方法相比，我们的方法提高了……
- `The results demonstrate the effectiveness of the proposed approach.`：结果表明，该方法是有效的。
- `However, the method still has limitations in...`：但是，该方法在……方面仍存在局限。
- `In future work, we will investigate...`：未来将研究……

### 7.4 一段练习材料

> To improve the detection of weak-texture defects, we introduce a lightweight attention module into the feature-fusion stage of a one-stage detector. The module first reweights feature channels and then highlights informative spatial regions. Experiments on a public steel-defect dataset show that the method improves the mean average precision while adding only a small computational cost.

**参考翻译：**

> 为了提高弱纹理缺陷的检测效果，我们将一个轻量级注意力模块引入单阶段检测器的特征融合阶段。该模块首先对特征通道重新加权，然后突出包含有效信息的空间区域。在一个公开的钢材缺陷数据集上的实验表明，该方法在只增加少量计算开销的情况下提高了平均精度。
