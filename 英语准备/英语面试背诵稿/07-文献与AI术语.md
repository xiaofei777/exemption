# 文献朗读、翻译与 AI 术语

## 朗读前

> Let me first find the main subject and the main verb.

我先找出句子的主语和主要谓语。

> This sentence mainly talks about the problem, the method, and the result.

这句话主要讲的是问题、方法和结果。

## 翻译卡顿时

> This part means that the method is designed to...

这部分的意思是，这个方法是用来……的。

> In simple words, the authors want to...

简单来说，作者想要……

> I do not know the exact term yet, but from the context it means...

我还不知道这个术语的准确含义，但根据上下文，它的意思是……

## AI 摘要常用句

- **To solve this problem, we propose...**  为解决这一问题，本文提出……
- **The method has three main parts.**  该方法有三个主要部分。
- **Compared with the basic method, our method improves...**  与基础方法相比，我们的方法提高了……
- **The results show that the method works well.**  结果表明，该方法效果良好。
- **However, the method still has limits in...**  但是，该方法在……方面仍有限制。
- **In future work, we will study...**  未来我们将研究……

## 练习段落

> To improve the detection of weak-texture defects, we add a light attention module to the feature-fusion part of a one-stage detector. The module first gives more weight to useful channels, and then highlights useful areas. Tests on a public steel-defect dataset show better mean average precision with only a small increase in computing cost.

为了提高弱纹理缺陷的检测效果，我们将一个轻量级注意力模块加入单阶段检测器的特征融合部分。该模块先提高有用通道的权重，再突出有用区域。在公开钢材缺陷数据集上的测试表明，计算开销只小幅增加，但平均精度有所提高。

## AI 术语短句

| English | 中文 | 简单解释 | 中文翻译 |
|---|---|---|---|
| overfitting | 过拟合 | The model is good on training data but bad on new data. | 模型在训练数据上表现好，但在新数据上表现差。 |
| gradient descent | 梯度下降 | It changes parameters to reduce the loss. | 它改变参数来减少损失。 |
| backpropagation | 反向传播 | It sends the error back to compute gradients. | 它把误差传回去计算梯度。 |
| convolutional neural network | 卷积神经网络 | It finds local patterns in images. | 它寻找图像中的局部模式。 |
| attention mechanism | 注意力机制 | It gives more weight to useful features. | 它给有用特征更高的权重。 |
| object detection | 目标检测 | It finds an object's class and position. | 它找出目标的类别和位置。 |
| intersection over union | 交并比 | It measures the overlap of two boxes. | 它衡量两个框的重叠程度。 |
| large language model | 大语言模型 | It learns language patterns from a lot of text. | 它从大量文本中学习语言模式。 |
| multimodal learning | 多模态学习 | It learns from different kinds of information. | 它从不同种类的信息中学习。 |
| agent workflow | 智能体工作流 | It connects a model, tools, memory, and steps. | 它连接模型、工具、记忆和任务步骤。 |
| inference latency | 推理延迟 | It is the time from input to result. | 它是从输入到结果所需的时间。 |
| ablation study | 消融实验 | It changes one part to test its effect. | 它改变一个部分来测试该部分的作用。 |
