- 回答结构：**定义 / 核心区别 → 原理 → 应用场景或优缺点**。

## 一、数据结构（优先级最高）

### 排序算法

- 冒泡 / 插入：`O(n²)`，稳定；插入排序适合基本有序数据。
- 选择：`O(n²)`，不稳定，交换次数少。
- 快速：平均 `O(nlogn)`，最坏 `O(n²)`，不稳定；可随机选主元优化。
- 归并：`O(nlogn)`，稳定，但需要 `O(n)` 额外空间。
- 堆：`O(nlogn)`，不稳定，额外空间 `O(1)`。

**Q：快速排序为什么最坏是 O(n²)？**  
答：每次选到最大或最小元素，划分极不平衡，递归规模变成 `n-1、n-2……`。

**Q：哪些排序算法稳定？**  
答：冒泡、插入、归并；快速排序、选择排序、堆排序通常不稳定。

### 树、图与查找

**Q：B 树和 B+ 树有什么区别？**  
答：B+ 树的数据都在叶子节点，叶子节点通过指针连接，范围查询和磁盘访问更高效。

**Q：AVL 树和红黑树有什么区别？**  
答：AVL 平衡更严格，查询快但旋转多；红黑树平衡要求较低，插入删除更高效。

**Q：DFS 和 BFS 的区别？**  
答：DFS 用栈或递归，适合回溯和连通性；BFS 用队列，适合无权图最短路径。

**Q：Dijkstra 能处理负权边吗？**  
答：不能，要求边权非负。

**Q：哈希冲突如何解决？**  
答：链地址法、开放寻址法、再哈希法。

**Q：栈和队列的典型应用？**  
答：栈用于括号匹配、函数调用、DFS；队列用于 BFS、任务调度和缓冲区。

## 二、操作系统

**Q：进程和线程的区别？**  
答：进程是资源分配的基本单位，线程是 CPU 调度的基本单位。同一进程的线程共享地址空间，但拥有独立的栈和寄存器。

**Q：死锁的四个必要条件？**  
答：互斥、占有并等待、不可剥夺、循环等待。

**Q：死锁如何解决？**  
答：预防、避免、检测与解除；银行家算法属于死锁避免。

**Q：分页和分段有什么区别？**  
答：分页固定大小，主要服务于内存管理；分段按逻辑划分、大小可变，更符合程序结构。

**Q：什么是虚拟内存？**  
答：利用磁盘和部分内存，为进程提供比实际物理内存更大的地址空间，通常通过分页实现。

**Q：FIFO、LRU、OPT 页面置换有何区别？**  
答：FIFO 淘汰最早进入页面，可能出现 Belady 异常；LRU 淘汰最长未使用页面；OPT 淘汰未来最长时间不会使用的页面，理论最优。

**Q：select、poll、epoll 的区别？**  
答：select 和 poll 需要遍历文件描述符；epoll 通过事件通知机制减少遍历，更适合大量连接。

**Q：什么是临界区？**  
答：访问共享资源的代码区域，需要通过互斥机制保证同一时刻只有一个线程进入。

## 三、计算机网络

**Q：TCP 和 UDP 的区别？**  
答：TCP 面向连接、可靠、有序，具有流量控制和拥塞控制；UDP 无连接、开销小、延迟低，但不保证可靠。

**Q：TCP 三次握手为什么是三次？**  
答：确认双方的发送和接收能力，并同步初始序列号，避免历史连接请求造成误建立。

**Q：TCP 四次挥手为什么是四次？**  
答：TCP 是全双工通信，两个方向需要分别关闭；FIN 和 ACK 通常不能合并完成。

**Q：TIME_WAIT 的作用？**  
答：确保最后一个 ACK 能到达对方，并让旧连接中的延迟报文在网络中消失。

**Q：TCP 如何保证可靠传输？**  
答：序列号、确认应答、超时重传、校验和、滑动窗口。

**Q：流量控制和拥塞控制的区别？**  
答：流量控制针对接收方处理能力；拥塞控制针对网络整体状况。

**Q：HTTP 和 HTTPS 的区别？**  
答：HTTPS = HTTP + TLS，能够提供加密、身份认证和数据完整性保护。

**Q：DNS 解析大致过程？**  
答：浏览器缓存 → 操作系统缓存 → 本地域名服务器 → 根域名服务器 → 顶级域名服务器 → 权威域名服务器。

**Q：常见 HTTP 状态码？**  
答：`200` 成功；`301/302` 重定向；`400` 请求错误；`401` 未认证；`403` 无权限；`404` 资源不存在；`500` 服务器错误。

## 四、计算机组成原理

**Q：Cache 为什么有效？**  
答：程序具有时间局部性和空间局部性，Cache 保存近期及附近的数据，减少访问主存的平均时间。

**Q：Cache 的映射方式有哪些？**  
答：直接映射、全相联映射、组相联映射。

**Q：一条指令的基本执行过程？**  
答：取指、译码、执行、访存、写回。

**Q：什么是指令流水线？**  
答：将指令执行划分为多个阶段，让多条指令重叠执行，提高吞吐率；常见冲突有结构、数据和控制冲突。

**Q：中断和异常的区别？**  
答：中断通常来自外部硬件；异常通常由当前指令执行引起。

**Q：中断和 DMA 的区别？**  
答：中断需要 CPU 参与数据传输；DMA 可以直接在内存和外设之间传输，减少 CPU 负担。

**Q：SRAM 和 DRAM 的区别？**  
答：SRAM 速度快、成本高、不需要刷新；DRAM 集成度高、成本低，但需要周期性刷新。

**Q：为什么 GPU 适合深度学习？**  
答：深度学习包含大量可并行的矩阵和向量运算，GPU 拥有大量并行计算单元和更高内存带宽。
