# 数据结构

## 排序算法

- 冒泡排序、插入排序：`O(n²)`，稳定；插入排序适合基本有序的数据。
- 选择排序：`O(n²)`，通常不稳定，但交换次数少。
- 快速排序：平均 `O(nlogn)`，最坏 `O(n²)`，通常不稳定；可随机选择主元。
- 归并排序：`O(nlogn)`，稳定，但需要 `O(n)` 额外空间。
- 堆排序：`O(nlogn)`，通常不稳定，额外空间 `O(1)`。

| 算法   | 平均时间     | 最坏时间     | 空间      | 稳定性 |
| ---- | -------- | -------- | ------- | --- |
| 冒泡排序 | O(n²)    | O(n²)    | O(1)    | 稳定  |
| 插入排序 | O(n²)    | O(n²)    | O(1)    | 稳定  |
| 选择排序 | O(n²)    | O(n²)    | O(1)    | 不稳定 |
| 快速排序 | O(nlogn) | O(n²)    | O(logn) | 不稳定 |
| 归并排序 | O(nlogn) | O(nlogn) | O(n)    | 稳定  |
| 堆排序  | O(nlogn) | O(nlogn) | O(1)    | 不稳定 |

**Q：快速排序为什么最坏是 O(n²)？**  
答：每次都选到最大或最小元素，划分很不平衡，递归规模变成 `n-1、n-2……`。

**Q：哪些排序算法稳定？**  
答：冒泡、插入、归并稳定；快速、选择、堆排序通常不稳定。

## 树、图与查找

**Q：B 树和 B+ 树有什么区别？**  
答：B+ 树的数据都在叶子节点，叶子节点用指针相连，范围查询和磁盘访问更快。

**Q：AVL 树和红黑树有什么区别？**  
答：AVL 平衡更严格，查询快但旋转多；红黑树平衡要求较低，插入和删除更快。

**Q：DFS 和 BFS 的区别？**  
答：DFS 用栈或递归，适合回溯和连通性；BFS 用队列，适合无权图最短路径。

**Q：Dijkstra 能处理负权边吗？**  
答：不能，边权必须非负。

**Q：哈希冲突如何解决？**  
答：链地址法、开放寻址法、再哈希法。

**Q：栈和队列的典型应用？**  
答：栈用于括号匹配、函数调用和 DFS；队列用于 BFS、任务调度和缓冲区。

## 稍详细理解

回答时可以补充：排序算法的选择要看数据规模、是否基本有序、是否要求稳定以及内存限制。B+树常用于数据库和文件系统，因为叶子节点顺序连接，范围查询只需顺着叶子指针读取。DFS 适合搜索所有可能路径，BFS 按层扩展，因此第一次到达目标时就是无权图的最短路径。
